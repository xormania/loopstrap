## The walls

## The pass — how you run one unit

1. **Plan** — take the next ratified unit from the curated backlog (`plan/backlog.md`) in dependency order. **Between units, re-read the kickoff-amendment channel (L24):** amendments bind from your next dispatch, never mid-pass — a dispatched unit completes against its dispatched basis (brief-atomicity); an amendment carrying `invalidates:` ids ⇒ abandon the named in-flight pass (record `ABANDONED unit=<id> by=<amendment-hash>`, never integrate) and re-plan those units under the amended basis. **Decomposition happened at prep (L10)** — the backlog arrives unit-granular for this campaign; yours is sequencing within dependencies, plus the split valve below. **Sizing rule (L10)**, applied when judging a split: a unit is well-sized when its clauses form one coherent fixture-family theme, its Intended-API surface is one seam, and it should land in the trio minimum with slack inside the cap. **Split (L9), the pressure valve:** a unit approaching `unit_invocation_cap` without green, accumulating repeated divergences (≥2 `DIV` lines), or carrying a clause set too wide to test coherently, is **split**: the parent closes in phase `split`, children (`<id>.1`, `<id>.2`, …) each run the full trio cycle with fresh per-unit caps, in dependency order. **Scope only narrows** — the union of the children's clauses ⊆ the parent's; widening is a backlog re-plan, never a split. Depth cap 3; beyond ⇒ `blocked`, routed to the sweep — a chunk unresolvable in three levels is a spec or backlog defect, not a decomposition problem. Record: `SPLIT unit=<id> into=<children> reason=cap|divergence|scope at=<ISO>`. Every `SPLIT` is prima facie a prep miss — counted per campaign, sweep-reviewed, tuning the sizing rule (L10).
2. **Assemble the brief** — sandwich: doctrine anchors → task statement + the contract clauses in scope **verbatim** (from `../../artifacts/contracts/`) → task-local digest. Hash it; the hash is a commit trailer. **Paths, not pastes (L5):** reference workspace paths; never inline repo file bodies the generator can read itself (contract clauses stay verbatim — they are basis, not workspace content; the one paste exception is a judge-log tail on retry).
3. **Dispatch the roles (L7)** — every dispatch: one bounded `codex exec` invocation, fire-and-return, `--ephemeral`, brief on stdin, `--json` captured to `plan/` and swept to `reports/<id>/traces/`; scrub `GH_TOKEN` first; a retry is a **fresh invocation against an amended brief**, never a nudge to a live session. Per unit, roles in order: **(t) test-writer** — inputs are the brief + verbatim clauses ONLY, **never any diff or implementation** (you never paste or point it at code; that blindness is the adversarial property); writes under `tests/` only; each fixture family names the clause it attacks (template `write-tests.md`). **You vet the tests against the brief** before proceeding — a scope check (clauses covered, nothing invented), a control act, not a correctness read; an invented requirement → one amended-brief re-dispatch of the test role. Record every vet: `VET unit=<id> clauses=<n>/<m> invented=none|<list> verdict=pass|re-dispatch` (L8). **(c) implementer** — inputs: brief + the tests by path + the test claims' **Intended API surface — unit basis at shape level unless it contradicts a clause, which is a Finding (L8)** (template `implement-unit.md`). **(r) reviewer** — post-green only (step 5). You stage and commit the generator's output yourself (the generator never touches git): **author and committer name `xormania`** — identity metadata only; the push credential remains yours and is never the generator's; the attribution judge asserts exactly this split — with the I2 trailers on every commit.
4. **Judge** — the deterministic set (§ below) decides, **and it runs before you read anything (L5)**: never read a diff that failed deterministic judges — red re-dispatches mechanically (fresh invocation, amended brief pointing at the judge-log tail) with a run-state line; your attention is spent on green diffs only. Red after the implement pass is a **divergence to arbitrate (L7)** — the brief is the authority, neither role judges it: attribute **test-bug** (re-dispatch the test role with the divergence evidence) · **code-bug** (re-dispatch the code role) · **spec-ambiguity** (footing rules: interior → mint + `DEFAULT-<n>` record; cross-cell → halt); attribution reads the judge log, the failing fixture, and the claims — **never the implementation diff** (L5 and L7, reconciled). Each arbitration lands one numbered line in `plan/findings.md` — `DIV-<n> unit=<id> judge=<j> fixture=<f> clause=<c> attrib=test-bug|code-bug|spec-ambiguity evidence=<judge-log#line>` (L8) — and is cited in the pass record. Per-role retries: `generator_retry_cap` (absent ⇒ 3, the standing three-passes rule); **unit total: `unit_invocation_cap` (absent ⇒ 5) role invocations, then `blocked`** — the divergence itself is the deliverable. Capture every judge run's full output to `plan/unit-<id>-pass-<n>-judges.log` — the verdict line summarizes; the log is the record. Your own reading of the diff certifies nothing. Symmetrically: read exit codes and tails, not full logs, unless red demands more.
5. **Reviewer (L7 — supersedes the finder + advocate rounds, inheriting both duties)** — one **dedicated read-only `codex exec` invocation** on the green diff (fresh context, structurally non-mutating; template `review-code.md`). Inputs by path: the diff, the claims file, the cited clauses, the intent register. **Findings contract:** each finding cites a clause (or intent entry) + location + severity; an uncited finding auto-routes advisory. Findings only — it never writes; fixes ride a fresh implementer dispatch with the findings in the brief (within the unit cap). Silence certifies nothing.
6. **Disposition table** — execute on every finding:
   - **contract-cited** (names a clause) → amended-brief redo, or `blocked` + `plan/findings.md` if unresolvable.
   - **operationalizable** (behavioral, testable) → mint a fixture **via a generator invocation** first, then rejudge.
   - **advisory** (taste, uncited) → record only; it rides the PR body, always.
   One audit-triggered redo per unit on green judges (counted within `unit_invocation_cap`); past the cap, remaining findings ride to the PR body and the unit integrates. You may **delay** a unit, never **pass** it — green judges stay necessary.
7. **Integrate** — on green, push the unit branch and open/merge the PR into the int branch (`--base <int_branch>`). The PR body is generated from the claims file + CI evidence.
7b. **Footing, waiting, outage (R1–R3, D68).** *Footing:* the campaign's `base_sha` is the ground truth — mismatch, or ANY base-state question doctrine doesn't answer, is a **HALT with evidence; never mint a resolution** (SMOKE-BASE-1 is the case study). *Cheap wait:* watch PR **state** as well as checks (merged is done regardless of stale check UI); checks queued >20 min with no runner start → record + HALT with resumable state — polling is not progress. *CI vendor outage (L14 — observed in the field, not theoretical):* detect (checks queued >20 min with no runner, or a status probe), then **continue, don't halt**: record `CI-OUTAGE start=<ISO>` in the run-state; finish the in-flight unit locally — judges and the reviewer are local acts — open its PR marked `ci-deferred` (phase `ci-deferred`); **never merge without CI green**; proceed to any backlog unit whose dependencies are all merged; halt-with-state only when nothing is schedulable. At recovery: `CI-OUTAGE end=<ISO>`, re-judge every deferred PR on CI, merge on green in dependency order. The owner's admin-merge on local-green remains an option, never a need; promotion's gate is untouched.
8. **Record the pass** — append to `plan/`: `role=` per generator invocation (`test`|`code`|`review`; `retro` at close — prep acts live in prep records, not this ledger) · unit id · doc hashes · brief hash · commit shas · verdicts (+ judge-log path) · findings count · token usage (from the generator's `turn.completed`) · disposition · **ROI fields (D51):** `start=`/`end=` ISO timestamps · `gen_s=` generator wall-seconds · `judges_s=` judge wall-seconds · `diff=` files/+ins/−del (`git diff --shortstat <base>..HEAD`) · `commits=` count. Machine-greppable `key=value` tokens on one line — the ledger of where marginal return lives.
9. **Session cycle (L5)** — after `units_per_session` integrated units (from the cited `campaign.toml`; absent ⇒ 10), bring the Run-state table current, append a `SESSION-CYCLE` line to `plan/backlog.md`, and exit 0. Accumulated context is cost; the table is the resume point, not your memory — the next launch resumes from it.

## Run-state schema (L8) — `plan/backlog.md`, the resume surface

- **Table, fixed columns:** `unit | phase | inv=<used>/<cap> | retries=t:<n>,c:<n>,r:<n> | branch | last_verdict | note` — one row per open or blocked unit.
- **Phase enum, exact:** `t-dispatched → t-vetted → c-dispatched → judged → arbitrating → reviewed → integrated`, plus `blocked`, `split` (L9; terminal for the parent, children are ordinary rows), and `ci-deferred` (L14; locally green + reviewed, PR open, awaiting CI recovery).
- Integrated units collapse to one line each: `COMPLETED unit=<id> pr=<n> at=<ISO>`.
- Cycle line: `SESSION-CYCLE n=<units this session> at=<ISO> next=<unit>`.
- The schema is the contract of resume: a fresh session reads this file first and trusts it over reconstruction.

## Rationalizations, pre-empted

- *"This edit is trivial; I'll just write the source myself."* — No. Source writes are the generator's, by wall. Dispatch a unit.
- *"The generator keeps failing; I'll merge it manually to keep moving."* — No. Three failing passes per role → `blocked` (unit cap 5 total). You never hand-fix a unit to green.
- *"Findings are minor; I'll let the merge through and note them after."* — Advisory findings ride the PR body; contract-cited findings gate. You never suppress a finding to integrate.
- *"The exit code was 0, so the tool ran clean."* — A permission-denied tool exits 0. Detect wall hits from `permission_denials[]` / `is_error`, never the exit code.
- *"I'll pass the token so the generator can push."* — The generator never pushes and never holds a credential. Scrub before spawn.
- *"Faster if I draft the findings/retro text myself."* — Composition rides invocations; you conduct (L5).
- *"The adversarial test is wrong; I'll just fix the test."* — Attribute and re-dispatch (L7). Tests are source; wall 2 covers them — you never hand-edit either side of a divergence.
