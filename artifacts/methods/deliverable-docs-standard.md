# The Deliverable Docs Standard — the plug (L26, v2 per L28)

**The contract.** Loopstrap consumes a fixed interface; your methods evolve freely
behind it (L28). This standard binds file names, grammars, the manifest, and the
validator — never how you derive terms, clauses, or judgments. One doc set per
member (L25); the set is the member's launch key.

## 1 · What the author delivers (7 files, into `<root>/artifacts/contracts/<member>/`)

| File | Content |
|---|---|
| `<member>-lexicon.md` | the vocabulary authority — authored first, authoritative over the contracts |
| `<member>-contracts.md` | the design authority — clauses under the grammar below |
| `<member>-experience.md` | the judgment register — advisory-to-reviewer force (or one line: `no experience surface`) |
| `clause-index.txt` | one line per clause: `<ID> <PARTY> <MUST|MUSTNOT|INV|GUAR|DEF>` |
| `term-export.txt` | one line per governed term: `<BANNED|REVIEW|QUALIFY|CANON> <term>` |
| `parties.txt` | one party per line (the segment map derives from this, L6) |
| `docs-manifest.toml` | the connector — schema in §3; **its verification licenses the member** |

Exports may be hand-authored or generated — the validator's cross-checks make
either safe.

## 2 · Grammars (what the machinery greps; everything else is your prose)

- **Clause anchor:** every clause begins at line start with its stable id in
  square brackets: `[C-SNAP-3] The snapshot owner MUST …`. IDs are party-prefixed,
  never renumbered; an amended clause keeps its id (delta log per §5).
- **Clause self-containment:** the text from the anchor to the next blank line
  quotes whole into a brief (verbatim-quotability).
- **Experience anchor:** `[X-1] …` per judgment entry — the reviewer cites these.
- **Term tiers:** the lexicon's enforcement grammar, consumed by the I1 judge
  directly: BANNED (hard fail) · REVIEW (adjudicated) · QUALIFY (bare noun —
  qualified form required) · CANON (the reserved form itself).
- **No dev-lane vocabulary anywhere in the set** — R6-enforced (these docs
  describe the deliverable, never Loopstrap; L25).
- **No unresolved markers:** `[drafting decision — confirm]` may not survive
  ratification.

## 3 · docs-manifest.toml (schema + shape)

```toml
member = "<member>"
version = "1"            # bump per ratified amendment
ratified = "YYYY-MM-DD"  # by the owner's hand

[files]                  # path = sha256, for every file in §1 except this one
"<member>-lexicon.md" = "<sha256>"
"<member>-contracts.md" = "<sha256>"
"<member>-experience.md" = "<sha256>"
"clause-index.txt" = "<sha256>"
"term-export.txt" = "<sha256>"
"parties.txt" = "<sha256>"

[law]                    # the member's standing-law lines (doctrine F-slots)
f4 = "<the ruled F4 line, once the docs name it>"

[judges]                 # bindings
profile = "rust"                       # DEFAULT (L32); resolves to <root>/artifacts/ci/profiles/<name>.md — named-but-missing profile = validator FAIL (L33)
local = []                             # optional command-list override
failure_vocab = "refusal=1 halt=2 fault=3 success=0"
fixture_corpus = "<path or 'none'>"

[deferrals]              # watched (L27): id = "binding trigger"
# "D-1" = "<the event that forces this to bind>"
```

## 4 · What Loopstrap generates (never the author)

- **`compiled-context/`** — anchors, term cards, digests, scaffold — generated at
  prep FROM the ratified set, regenerated by the ripple on every amendment,
  delivered verbatim in the brief sandwich (L27). Derived, never hand-drifted.
- The segment map, guidance memos, plans — the whole downstream (L6/L10/L12).

## 5 · Validation and the plug act

`artifacts/instance/tools/docs-verify.sh` is the gate: manifest hashes ·
clause-index ↔ contracts bijection · parties coverage · term-export terms present
in the lexicon · experience anchors (or the declared absence) · marker sweep ·
the R6 wall over the triad. **Ratification = validator exit 0 + the owner's hand
landing the set.** Amendments: stable ids, per-clause delta log, version bump,
re-verify, then the ripple (L24) re-evidences completed work and regenerates the
derived layers.
